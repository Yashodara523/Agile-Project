# 6. RACI Matrix

**R** = Responsible (does the work) · **A** = Accountable (owns the outcome, one per row) · **C** = Consulted · **I** = Informed

| Activity | PM | BA | UI/UX | Developers | QA | Supervisor |
|---|---|---|---|---|---|---|
| Project charter | A/R | C | C | C | C | C |
| Stakeholder management | A/R | R | C | I | I | C |
| User research and interviews | A | R | R | I | I | I |
| Requirements and acceptance criteria | A | R | C | C | C | I |
| Backlog prioritisation | A | R | C | C | C | C |
| Sprint planning | A/R | R | R | R | R | I |
| Daily stand-up facilitation | A/R | I | I | I | I | - |
| Personas, wireframes, design system | C | C | A/R | C | I | I |
| Architecture and technical setup | C | I | I | A/R | C | I |
| Feature development | I | C | C | A/R | C | - |
| Code review | I | - | - | A/R | C | - |
| Test strategy and test cases | C | C | I | C | A/R | I |
| Accessibility testing | C | C | C | R | A/R | I |
| Usability testing | A | R | R | I | R | C |
| Defect triage | A/R | C | C | R | R | I |
| Risk management | A/R | R | R | R | R | I |
| Sprint review and demo | A/R | R | R | R | R | C |
| Retrospective | A/R | R | R | R | R | - |
| Deployment and release | A | I | I | R | R | I |
| Status reporting | A/R | C | I | I | I | I |
| User manual | A | R | R | C | C | I |
| Final report | A/R | R | R | C | C | C |

**Single-point accountability:** where two letters appear (A/R), the same person owns and executes the activity.
